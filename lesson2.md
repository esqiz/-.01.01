# Введение в C++

## Язык программирования C++

Язык программирования C++ представляет собой высокоуровневый компилируемый язык программирования общего назначения со статической типизацией.

Своими корнями он уходит в язык C, который был разработан в 1969-1973гг.  компанией Bell Labs программистом Деннисом Ритчи.

**В начале 1980-х годов датский программист Бьерн Страуструп, который в то время работал в компании Bell Labs разработал C++, как расширение к языку C.**

**Фактически в начале C++ просто дополнял язык C некоторыми возможностями ООП. Изначально язык назывался "C с классами".**

**C++ является компилируемым языком, а это значит что компилятор транслирует исходный код на C++ в исполняемый файл, который содержит набор машинных инструкций.**

### Зачем нужно компилировать исходные файлы
Исходный C++ файл это всего лишь код, но его невозможно запустить как программу или использовать как библиотеку, поэтому каждый исходный файл требуется скомпилировать в исполняемый.

### Этапы компиляции
1. **Препроцессинг**. Это макропроцессор, который преобразовывает программу для дальнейшего компилирования. На данной стадии происходит работа с препроцессорными директивами. Например, препроцессор добавляет хэдеры в код (#include, убирает комментарии).
2. **Компиляция**. Преобразование в ассемблерный код. Это промежуточный этап между высокоуровневым языком и машинным кодом.
3. **Ассемблирование**. Перевод ассемблерного кода в машинный <br> Объектный файл это созданный ассемблером промежуточный файл хранящий кусок машинного кода. Этот кусок машинного кода, который ещё не был связан с другими машинного кода называется объектным кодом.
4. **Компоновка**. Компоновщик (линкер) связывает все объектные файлы и статические библиотеки в единый исполняемый файл, который мы можем пропустить.
5. **Загрузка**
