# Введение в C++

## Язык программирования C++

Язык программирования C++ представляет собой высокоуровневый компилируемый язык программирования общего назначения со статической типизацией.

Своими корнями он уходит в язык C, который был разработан в 1969-1973гг.  компанией Bell Labs программистом Деннисом Ритчи.

### В начал 1980-х годов датский программист Бьерн Страуструп, который в то время работал в компании Bell Labs разработал C++, как расширение к языку C.

### Фактически в начале C++ просто дополнял язык C некоторыми возможностями ООП. Изначально язык назывался "C с классами".

### C++ является компилируемым языком, а это значит что компилятор транслирует исходный код на C++ в исполняемый файл, который содержит набор машинных инструкций.
